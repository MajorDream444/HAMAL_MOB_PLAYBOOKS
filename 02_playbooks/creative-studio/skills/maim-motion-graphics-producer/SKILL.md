# Motion Graphics Producer

Read [production-contract.md](references/production-contract.md) before production.

Version: 0.1.0

## Workflow

1. Choose deterministic compositing for exact typography, logos, charts and timing. Use generated footage for backgrounds or scenes where needed. Keep the exact mark and copy separate from generative footage.

2. Load an approved style and source assets. Define duration, aspect ratio, typography, color values, safe areas, transitions and audio rights. Label any missing assets instead of substituting a fake logo.

3. Write a timeline with in/out times, position/scale/opacity curves, easing, captions and audio cues. Ensure motion respects reduced-motion needs in web previews.

4. Use an available rendering skill/tool (such as Remotion, HyperFrames or a compositor) and follow its instructions. Export only formats actually rendered. Do not treat a storyboard as a finished video.

5. Check first/last frames, text legibility, frame dimensions, audio clipping/sync and continuity. Record render version, tool and dependencies. Deliver editable project, rendered clip and static fallback when applicable.
