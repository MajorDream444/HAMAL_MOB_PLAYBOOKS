# Layered Cover Builder

Read [production-contract.md](references/production-contract.md) before production.

Version: 0.1.0

## Workflow

1. Use the approved cover image as the comparison reference. Inspect PDF objects first; distinguish live text, placed rasters and actual layers. Never promise original hidden layers can be extracted from a flattened image.

2. Separate background, subject/masks where feasible, live title, subtitle, exact logo, author line and edition label. Reconstruct obscured areas only where necessary and label them reconstructed. Do not silently redesign. Session approval covers both A/B design families; choose a reversible pilot option and label the choice rather than blocking on a new approval. Draft back copy does not invalidate approved visual direction.

3. Preserve The Architecture of Integrity (adult 18+), The Integrity Code (13-17) and The Truth Compass (7-12), each with approved A/B directions. Preserve the paths, exact mark and supplied portrait.

4. Build the back from editable copy, portrait, logo and reserved barcode area. The v0.4 packet leaves copy/bio review, ISBN, trim, spine and bleed pending. Do not invent these or label the jacket print-ready.

5. Compare an aligned render against the approved reference. Check spelling, hierarchy, mark proportions, crop and small text. Retain native editable master plus interchange format; verify layer preservation in the chosen format.

6. Output layer manifest, preview, source package and outstanding print decisions. Record whether font is exact, substituted or custom lettering; a wordmark is not a complete font.
