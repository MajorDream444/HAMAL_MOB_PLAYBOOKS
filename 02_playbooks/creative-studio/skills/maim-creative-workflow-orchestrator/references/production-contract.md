# Production contract

Preserve originals and approved references. MAIM and HAMAL spelling is mandatory. Never generate a substitute Major Dream logo.

Job fields: id, brief, brand, workflow, source_asset_ids, skill_versions, status, owner, budget_ceiling, provider, outputs, checks, unresolved.

Asset fields: id, source, checksum, owner, rights, approval_status, version, parent_id, category.

Status values: planned, blocked, running, review, completed. Missing files or provider access must be explicit blockers.

Skill registry fields: name, version, description, dependencies, input_contract, output_contract, validation_state, evaluation_evidence, source_path.

Never infer brand approval from visual similarity. Generation can vary; use review and reusable components for consistency. External provider work may cost money even when the interface is open source.
