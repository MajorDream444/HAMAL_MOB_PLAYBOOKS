# Storyboard & Continuity

Read [production-contract.md](references/production-contract.md) before production.

Version: 0.1.0

## Workflow

1. Load approved character references, wardrobe, campus views, brand rules and target story. Treat 13 campus buildings and 144 agents as narrative context, not evidence that a deployed campus exists.

2. Create a cast and set register with stable IDs. For each shot record duration, framing, camera movement, subject action, location, light, dialogue/audio, reference IDs, entry frame and exit condition.

3. Prefer simple, filmable actions. Check total duration and transitions. Use an approved outgoing frame as the next reference when appropriate, but review for accumulated identity or geometry drift.

4. Produce a storyboard and prompt per shot. Keep identity, wardrobe, signage and spatial continuity explicit. Do not invent provider parameters, supported model names or guaranteed reference consistency.

5. Use generic provider-neutral shot records first. Verify current official API schema before producing provider payloads. Missing adapters remain unconnected; do not claim prompts execute generation.

6. Output shot list, reference checklist, prompt package and continuity review. Reuse established session authorization; obtain decisions only for new creative choices that materially change the approved direction.
